# Agentic AI student support

Two small college assignments. Each folder runs on its own. Python standard library only. No API key.

| Folder | What it is | Run |
| --- | --- | --- |
| `assignment1-student-support` | Chat agent for fees, scholarships, the handbook, and memory | `python app.py` then open http://127.0.0.1:8765 |
| `assignment2-safe-student-support` | The same agent, plus sign-in, access checks, staff approval, and an audit log | `python app.py` then open http://127.0.0.1:8766 |

Demo student records and PINs are fake sample data, documented in each README. Evaluation results are in each folder’s `evaluation.md`.
